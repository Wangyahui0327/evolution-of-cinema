RQ1 · How have movie genres evolved over time?

Annual film counts for the top 8 genres, aggregated by decade. Films may have multiple genres, so genre totals can exceed unique films. Select a genre using the legend or the global filter.

RQ2 · How do production patterns differ across countries and decades?

Production-country × release-decade heatmap. Colour encodes film count in the currently selected subset. Click a row to filter that production country; co-productions can contribute to several countries.

RQ3 · How have actor–director collaborations evolved?

Repeated collaborations

Top recurring director–actor pairs in the selected decade. Nodes represent people; links represent at least two jointly credited films during that decade. Click a node to highlight its connections. Network uses a precomputed decade-level sample and is not affected by country or genre filters.

RQ4 · Do genres differ in critical reception?

Rotten Tomatoes score distributions by genre. Box = interquartile range, line = median; whiskers = minimum / maximum in the selected sample. Only movies with recorded scores are used.

Critical reception over time

Median Rotten Tomatoes percentage by release decade, with sample sizes available on hover. This is descriptive rather than causal.

Movie explorer · Details on demand

Up to 25 matching films are shown. Change filters to explore. A missing RT score is shown as “—”; it is never treated as zero.

Method: linked filters run on the unique film-level dataset using Crossfilter2. D3.js draws the custom charts. The original movie / genre / cast / crew / award tables are processed in advance; not all rows are duplicated in the published site.

Data caveats: Film years and countries describe entries in the source movie metadata rather than global production output. Production country does not represent viewer location or local box-office markets. Rotten Tomatoes data are missing for many titles. Genre labels reflect the source taxonomy (including some specialist categories); films may have more than one genre. Crew network shows a restricted recurring director–actor subset (first six credited cast records where ordering exists); absence of an edge does not imply absence of collaboration. No causal inference is claimed. Source: user-provided five-table movie metadata dataset.
